## 本轮新增/修复的实际场景

- 同一数据目录重复启动：新进程退出，现有记录保留；两个不同用户数据目录与管理员窗口同时运行。
- 一个账号加入两个组：每组子管理员角色独立；跨组、撤权、停用和其他用户提交的写入被拒绝；无组没有工作台。
- 管理员设置离线有效期；在线核验采用新期限；断网允许已有授权内工作，过期禁止新轮次。
- 自己修订待整理成果；子管理员编辑和合并；整理后原作者删除、修改、替换均被拒绝；文件替换保存新修订；旧版文件可由子管理员纳入管理。
- 同一版本并发保存只有一个成功；上传成功但回执丢失，重试不新增重复项，也不恢复已经整理的原件。
- 每个项目均可创建/更新资料；`.keep` 不影响初始化；新会话默认冻结引用，资料更新提示不改变现有快照，显式采用才切换版本。
- 只有对话没有工作记录也能取材；整理输入冻结后，后续消息变化不会改写输入；补充、重试、取消及真实上传状态保留。
- 公共成果搜索、原作者/维护人/版本展示、加入会话形成可读 Markdown 快照并选中引用；1100 像素窗口检查。
- Git 非仓库、未提交仓库、已提交、dirty 工作区；可不附带版本信息；成果包不包含代码和整理输入。
- 轨迹连续点击去重，工具事件变化也形成新版本；自动间隔后补传；成功时间只在完成后填写；清理缓存保留原会话和工作记录。
- 最后一位子管理员降级或停用须指定接任或保留空缺，其他组身份保留。
- Codex/Cursor 登录识别、模型与额度、待授权通知、权限模式、后台整理、关闭会话、中文输入法/Enter/Shift+Enter 均完成回归。

## 验证的限制

回环 SSH/SFTP 测试使用协议服务，Python 在 Windows 上模拟 Linux 账号与 chown/chmod；它们不验证内核权限。真实 Linux 的 systemd 安装、sshd/PAM 和 ACL 拒绝绕过尚未执行。已提供可在 Linux root + acl 环境运行的内核权限测试，生产首次部署仍需完整 SSH 端到端验收。操作方法见 [身份与协作说明](identity-content.md)。

没有重新消耗个人模型账号运行比赛业务，也没有执行新安装包的跨电脑迁移测试。
