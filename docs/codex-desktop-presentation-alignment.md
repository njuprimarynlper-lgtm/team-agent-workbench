# 已有能力的桌面交互对齐

分支：`codex/desktop-presentation-alignment`。核对日期：2026-10-26。

用户要求对齐 Codex 桌面版的操作逻辑：在哪里操作、右键有哪些动作、发送后怎样反馈、如何处理排队和失败。保留工作台原有视觉风格和页面布局。此前尝试的整套换色、侧栏重排和设置页重排已撤回。

尚未实现的能力另存于 [CLI 能力缺口清单](codex-cli-gap-inventory.md)，本轮不新增那部分能力，也不把团队功能伪装成 Codex 原生功能。

## 本轮调整

| 操作位置 | 交互逻辑 |
| --- | --- |
| 左侧会话右键 | 操作被点击的会话，不切走当前对话；可重命名、移动到项目或分组、创建子会话、关闭。子会话可升级为独立会话。只显示已有且可用的动作 |
| 会话重命名 | 原位输入，回车保存、Esc 取消；保留原有双击和 F2 入口 |
| 消息右键 | 复制消息；选中文字时可复制选区；添加到会话只填入草稿；可用时提供已有的侧边提问入口。链接和输入控件保留自身行为 |
| 普通发送 | 回车立即清空已提交草稿，并在对话中显示待发送内容；后台接收后使用正式消息，不重复显示；发送期间可继续写下一条草稿 |
| 发送失败 | 显示失败信息；输入框未被编辑时恢复原稿，已写新草稿时保留新草稿，并提供恢复上一条消息的入口。不自动重发 |
| 执行中继续输入 | 回车加入待发送队列，不冒充已送入模型的消息；待当前轮结束后依次执行；“引导”仍明确用于当前轮 |
| 队列消息 | 每条保持紧凑单行，过长省略；点击查看全文；可编辑、移除、拖动排序，或右键提前／推后一条；正在发送的条目不可重排 |
| 队列暂停 | 保留停止、错误及重启后的暂停保护；编辑时暂停队列，避免编辑中的内容被自动发出，用户点击继续后恢复 |
| 输入历史 | 主会话、子会话输入框为空时按 ↑，恢复上一条用户消息到草稿；不会自动发送 |
| 阅读对话 | 在底部时跟随新回复；上翻历史时保持阅读位置，提供“回到最新消息”按钮；主会话、子会话和侧聊保持相同规则 |
| 模型结构化提问 | 候选项直接可点击；单选、原生支持的多选、自由文本与跳过按协议处理；输入其他答案会取消先前单选，必答项完整后才可提交 |
| 菜单和弹窗 | 右键菜单支持方向键、Home/End、Esc 和点击外部关闭；会话“更多”支持键盘移动；通用弹窗支持焦点限制、Esc 关闭和焦点返回 |
| 子会话 | 模型、模式、权限在输入栏内操作；沿用主会话发送反馈和草稿保护；不重建执行上下文 |

## 保留的能力与边界

- 模型、思考程度、Plan/Agent、Skill、插件、MCP、权限和账号额度继续使用已有输入栏入口。切换配置不打断当前回复。
- 附件、项目资料和共享成果的引用仍在下一次发送时进入模型；撤销未发送引用的行为不变。
- 工具执行过程默认折叠，正文、代码、表格、图表继续使用原有渲染和限宽。
- 导入会话、桌面同步、关闭／恢复、子会话上下文、工作目录和项目权限沿用已有业务语义。
- 项目设置、成果整理、共享成果、团队动态、提问、任务、AI 推荐、传输记录及管理端保留原有业务流程。Codex 没有对应的团队页面，本轮不强行重排。
- Codex/Claude 的结构化提问提交文本，Cursor 的选项按其协议提交 ID；可用权限和原生同步能力仍依据各 CLI 实际支持情况。
- 临时侧聊保持不能在执行中追加发送的既有边界；本轮没有给它增加独立队列。
- 不新增编辑已发送历史、原生置顶／未读状态等底层未接入能力。

## 验证

测试使用独立数据目录和 IPC／CLI 打桩，不读取个人对话、连接中央节点或消耗模型额度。

- `npm run typecheck`、`npm run build`：类型检查与用户端、管理端构建。
- `npm run test:desktop-interactions`：生产 React 页面，验证右键、原位重命名、复制／引用、发送等待与失败、新草稿保护、队列全文／重排／编辑／移除、历史滚动、结构化问题及三种窗口宽度。
- `npm run test:composer-ui`：Electron 与打桩 CLI，验证 Codex/Cursor 输入、中文输入法、工具选择、模式、模型和权限切换、上下文与草稿保留。
- `npm run test:questions-ui`：Electron 与打桩 CLI，验证问题选项和各 provider 的回答协议。
- `node scripts/side-chat-ui-smoke.mjs`：临时侧聊、草稿、关闭及失效状态。
- 基础用例覆盖乐观发送、队列顺序／失败／竞态、等待消息去重、子会话、消息记录及授权。

截图输出：`artifacts/desktop-interactions/`。截图和 `.test-data/` 属于本地验证产物，不纳入版本跟踪。

启动仍使用根目录的 `start-user-dev.cmd`、`start-admin-dev.cmd`，没有新增启动器。

## 参考依据

- [Codex 提示与后续消息](https://learn.chatgpt.com/docs/prompting)：桌面队列、引导和后续消息行为；桌面与 CLI 的默认按键行为不能混用。
- [Codex 命令与快捷键](https://learn.chatgpt.com/docs/reference/commands)：空输入框恢复上一条输入、会话操作与键盘入口。
- 本机已安装 Codex 桌面程序的队列及消息组件：核对等待提交、失败保留、队列预览和操作语义。没有操作正在进行的原生会话。

这是已有能力在当前接口范围内的交互对齐，不代表完整复制 Codex 桌面宿主能力。
