# 输入框内容入口（v2.3.43）

主会话和子会话的 `＋` 菜单统一为：本地文件、项目成果、Skills、MCP 工具、插件。前两项与工具入口之间使用分隔线，根菜单不展示说明文字或指令代码。Skills 和插件在同一弹层的第二级选择，支持返回、搜索、点击外部及 Esc 关闭。原有键入 `/`、`$`、`@` 的能力继续保留；Claude 原生斜杠指令仍交给 Claude CLI。

菜单按实际能力启用：Cursor 插件由 CLI 配置加载，工作台未提供 Claude MCP 管理；对应入口置灰并说明原因。开启摘要 Beta 时保留额外的手动摘要引用入口。

## 本地文件

选择文件只保存绝对路径和元数据，不复制文件、不读取文件正文、不计算内容哈希。模型收到路径后按需读取原文件当前内容。发送前检查文件仍可读，缺失时明确报错。同一路径重复选择复用原引用，已经发送的路径可以再次选入下一轮。

取消引用不会删除原文件。已发送引用保留在历史中，撤销只影响待发送选择。子会话继承相同路径，不为路径引用另做文件副本。项目目录迁移不会悄悄改写手动选择的绝对路径。

新引用使用 `SourceFile.referenceMode = 'path'`，`sha256` 字段仅作为稳定的路径回执，不表示内容哈希，也不展示给模型。旧引用、成果正文/附件、项目资料和整理输入继续使用各自原有的快照规则；整理成果时冻结输入属于独立操作。

## 分享至团队

点击“分享至团队”直接提交，不再强制弹出确认或目录选择。首次分享使用成果分类根目录；更新保留原团队目录。需要指定路径或选择公开直接来源时，使用独立的“选择目录分享…”操作。
