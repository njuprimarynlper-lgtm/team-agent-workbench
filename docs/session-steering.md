# Codex 会话中的跟进消息

主会话和子会话使用相同的跟进设置。默认按 Enter 将补充内容放入下一轮队列，按 Ctrl+Enter（macOS 上为 ⌘+Enter）引导正在运行的轮次。可在「agent管理 → Codex 跟进处理方式」中交换这两个操作。Shift+Enter 换行。上下文压缩期间，两种跟进操作都会排队。

- 点击一条排队消息可查看全文。铅笔将该条消息及所选引用、Skill 和插件放回主输入框。Enter 保存，Esc 或「取消编辑」恢复原文，两种操作都会找回编辑前的草稿。编辑期间，其余消息仍可按顺序发送。
- 队列支持逐条移除、撤销删除、调整顺序，以及转到侧边聊天继续编辑。引导针对发送时的原生轮次。送达状态不明时，先核对对话记录。明确失败的引导可单独重试，原轮次结束后可手动改为下一轮发送。
- 单击停止按钮或在输入区连续按两次 Esc 会停止当前任务并暂停队列。用户可手动继续队列。输入法组字期间的 Enter 和 Esc 用于完成或取消组字。
- 空闲的 Codex 会话中，最近一条可核对的用户消息旁显示编辑按钮。取消保留原对话。重新发送会替换该轮对话，已执行的文件修改会保留。工作台先向 Codex 核对原生轮次和原始消息，保存恢复稿后再执行回退。旧版 CLI 的按数量回退仅用于工作台独占的会话。

Cursor 和 Claude 延用各自的排队与发送方式。
