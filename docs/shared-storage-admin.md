# 共享空间管理

管理员版左侧的“共享空间”面向总管理员提供只读、图形化的全局占用视图。本地文件系统打桩和 Linux / SSH 模式使用相同统计口径。项目子管理员仍在用户版维护自己负责的项目内容，不能调用全局空间统计。

## 页面与统计口径

- 顶部显示共享文件总量、所在磁盘剩余容量、项目组与项目数、成员共享占用。
- “内容构成”环形图区分成员成果、会话轨迹、团队整理、项目公共内容、系统数据和未归属内容。
- “项目组”按总占用绘制横向比例条，并列出成员提交、轨迹、团队整理、项目公共内容和未归属内容。
- “用户”汇总每个账号在全部所属组中的成果提交与轨迹。成员本机目录、Linux Home、Codex/Cursor 本地会话和 Git 仓库不在统计范围内。
- “文件夹”按需扫描当前目录的直接子目录，显示递归占用、直属文件占用、文件数、子目录数和最近变化；每次最多返回 100 条，可继续加载。

用户占用来自 `项目/submissions/<用户>/` 与 `项目/trajectories/<用户>/`。`curated/` 归项目组公共空间，无法映射到已登记项目组或成员的文件进入“未归属”。因此用户占用之和通常小于共享空间或项目组总量。

目录大小使用普通文件的逻辑字节数。磁盘容量来自共享根目录所在卷或分区，两者含义不同。页面显示统计时间，进入页面时自动统计一次，此后由管理员手动刷新；不会定时轮询服务器。

## 执行和权限

本地模式由管理员进程使用 `lstat` 扫描已连接的本地共享根目录。Linux 模式通过现有 root/sudo SSH 管理连接执行固定的 `storage_usage` Python 操作。请求只接受共享根目录内的相对路径，服务端重新验证路径。

扫描不读取文件内容、不修改 ACL、不取得用户凭据，也不写入团队登记。符号链接、目录联接和非普通文件不会被跟随；读取失败或扫描期间消失的路径作为警告显示。统计和用户管理使用独立的忙碌状态，扫描不会锁住团队登记或用户上传。管理员可以取消正在运行的统计。

当前版本不提供配额、删除、移动、压缩或自动清理。相关能力需要另行定义回收站、审批、留存和审计规则。
