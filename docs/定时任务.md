# 本机定时任务

左侧“定时任务”按项目管理自动执行的工作。新建时先选择项目，再填写说明、执行时间、模型、思考程度、网络和权限。支持单次、每隔若干小时、每天、工作日和每周指定日期。

每次运行新建独立的 Codex CLI 会话，使用该项目最新的本地资料快照，并记录版本。补充说明和参考附件只属于这个任务。修改项目公共资料会影响后续运行，不改变已经完成的记录。中央节点未连接时使用本地缓存；选择管理端网络的任务仍需要对应出口可用。

任务和历史只保存在本机当前账号中，不同步到 Codex 桌面端，也不通过账号同步在其他电脑重复执行。每个账号按到期顺序执行，同一任务已有排队、运行或等待授权的记录时不重复入队。任务权限沿用普通会话；需要授权或回答问题时会等待，并显示系统通知。

关闭窗口后工作台留在托盘运行。双击托盘图标或选择“打开工作台”返回；选择“退出工作台”停止后台调度。电脑关机、休眠或工作台退出期间不执行，恢复时跳过错过的计划；中断的运行不会自动重放，可检查已有结果后选择“立即执行”。本版不增加开机自启。

执行结束的会话保存在“运行记录”，不占普通工作会话和已关闭会话列表，也不进入跨会话日志。点击记录查看完整对话，向上持续滚动每次加载更早的 160 条消息。“继续对话”将原来的会话加入普通工作会话，后续定时执行仍新开会话。

暂停只阻止后续触发，当前运行可以单独停止。历史默认保留，支持多选删除。删除任务时可以选择同时删除历史；已经加入普通工作会话的对话会保留。运行中的记录需先停止才能删除。

默认使用项目配置的本地目录；项目未配置目录时，分配任务固定目录。会话历史独立不代表项目文件隔离；指向同一目录的任务和普通会话仍可修改同一份文件。

成果整理、传输记录和成员名片统一放在左侧“更多”菜单中，成果提醒保留在菜单入口。
